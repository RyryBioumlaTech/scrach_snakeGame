# 🐍 Scratch Snake Game – DOM Engine Experiment

A pure **JavaScript experiment** to recreate the classic Snake game **without canvas, without frameworks, and without tutorials**.  
100% DOM manipulation — coded from scratch using logic only.

---

## 🎯 Project Objective

This project is a **technical exploration**:

> How to build a minimalist game engine using only the **DOM**, without `<canvas>` or external libraries.

The goal is not raw performance, but a **deep understanding** of how the browser handles:
- Real-time element rendering  
- Collision management  
- Animation and movement synchronization  
- Dynamic body propagation through the DOM  

---

## 🧠 Features

- 🎮 Smooth movement with arrow keys  
- 🍎 Random food generation  
- 🐍 Dynamic snake growth (new DOM segments added)  
- 💥 Self-collision and wall detection = *Game Over*  
- 🧾 Live score display and retry panel  

---

## ⚙️ Technologies

| Language / API | Role |
|----------------|------|
| **HTML5** | Structure of the game scene and UI elements |
| **CSS3** | Board layout and snake styling |
| **JavaScript (ES6)** | Core game logic, movement, collisions, and state management |
